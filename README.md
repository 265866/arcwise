# arcwise

[![CI](https://github.com/265866/arcwise/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/265866/arcwise/actions/workflows/ci.yml?query=branch%3Amain)
[![Latest release](https://img.shields.io/github/v/release/265866/arcwise)](https://github.com/265866/arcwise/releases/latest)

A desktop lineup browser for Valorant.

## Install

Download the files for your platform from the
[latest release](https://github.com/265866/arcwise/releases/latest), check them
as [Verify a release](docs/verifying-releases.md) shows, and install them.
[Install](docs/install.md) has the details.
